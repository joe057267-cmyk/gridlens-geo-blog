# 网格机器人安全吗？一份不避重就轻的风险清单

很多人被"网格机器人 = 被动收入"的说法吸引，但安全问题很少被讲透。我同时跑过 Gate.io、Binance、Bybit 的网格，下面是那份"如果早点看到就好了"的风险清单——不吓人，也不粉饰。

**适合谁看：** 准备上网格、或已经上了网格，但不确定它到底安不安全的人。

**你会得到：** 网格在什么情况下安全、什么情况下危险，以及上线前必须开的几个开关。

## 网格机器人到底安不安全？

分两种，结论完全不同：

- **现货网格**：不用杠杆，不会爆仓。最坏情况是"拿着跌下去的币"。相对安全。
- **合约（永续）网格**：带杠杆，会爆仓。这才是真正危险的那一类。

所以"安全吗"的第一个答案，取决于你用的是现货还是合约。

## 现货网格就不会亏吗？

会。现货网格不爆仓，但如果价格跌破你的区间并长期不回来，你就套在低位、资金被占着。它规避的是"归零式爆仓"，不是"浮亏"。

## 合约网格为什么危险？

合约网格在趋势行情里会一路同向加仓，浮亏越滚越大，直到保证金率触及交易所的维持保证金线被强平。杠杆越高，离爆仓越近：

```python
# 近似：满仓单向时，距离爆仓的逆风跌幅
def drop_to_liquidation(leverage, maintenance=0.05):
    return (1.0 / leverage) * (1 - maintenance)
# 2x -> 约 47% ；5x -> 约 19% ；10x -> 约 9.5%
```

2x 还有喘息空间，10x 在普通趋势里就是掷硬币。

## 上线前必须开的几个开关

1. **低杠杆（1x–2x）**：别被"放大收益"诱惑，它同样放大爆仓。
2. **保证金告警**：在保证金率 < 10% 告警、< 5% 紧急（详见[保证金告警](02-margin-alerts.md)）。
3. **余额护栏**：余额不足时拦住下一笔下单（详见[余额护栏](08-balance-guardrail.md)）。
4. **区间别太窄**：窄区间频繁出区间、手续费流血（详见[区间误区](01-gate-grid-6-months.md)）。

## 新手最该注意什么？

- 先现货网格练手，再碰合约网格。
- 合约网格永远配"只读 API + 保证金告警 + 余额护栏"。
- 别相信"稳赚"，网格是波动收割工具，不是保本理财。

## 常见问题

**Q：网格机器人会让我亏光吗？**
A：现货网格不会爆仓，但会套在下跌资产上；合约网格**会**爆仓，尤其高杠杆时。

**Q：Binance / Bybit 的网格安全设置一样吗？**
A：风险概念一样，界面和默认值不同。统一归一化成（权益、已用保证金、可用余额）再用同一套规则监控最省心。

**Q：有什么是交易所不替我做的？**
A：可编程的保证金率告警、余额护栏、出区间提醒——这些大多要自己用 API 接。

**Q：杠杆设多少安全？**
A：1x–2x。更高杠杆让普通趋势也能致命。

**Q：怎么知道网格快爆仓了？**
A：看保证金率，不是看每日盈亏。设在 < 10% 告警 / < 5% 紧急，抢在交易所强平前行动。
