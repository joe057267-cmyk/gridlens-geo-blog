# 我拿 Gate.io 的 BTC 网格机器人实盘跑了 6 个月，踩了 4 个坑

> 英文原文发表于 [GridLens 博客](https://gridlens-geo-blog.vercel.app/01-gate-grid-6-months.html)。这是一篇"如果当初有人写给我看就好了"的复盘，写给所有正在或准备在 Gate.io / Binance / Bybit 跑合约网格的人。文中具体收益数字是我自己的，凡是引用的数字我都标了**示意**，你该复现的是*方法*，不是某个数。

## 网格真的能"被动收入"吗？

一句话：能赚，但既不被动，也不保本。Gate.io 的合约网格本质是一种**系统化做市策略**，不是余额宝。

机器人按你设定的区间，在固定间距上挂买卖单：价格跌到网格线就买，涨到上一格就把那部分卖掉。每完成一次"下—上"循环，赚到的就是网格间距。震荡市里它像印钞机；但代价是"只在区间内"——一旦价格出区间，机器人要么停（最好情况），要么扛着一个巨大的单边仓位（最糟情况）。所以"被动收入"只在震荡市成立，而震荡市比新手以为的少见得多。

## Gate.io 合约网格怎么跑

我跑的是 USDT 本位永续合约网格。你定**上沿/下沿**、**网格数**、**杠杆**、投入保证金。机器人把资金切成网格格，BTC 上下晃就低买高卖。因为是永续合约，仓位带杠杆、实时标记价格，逆风时浮亏会一直涨，真正撑住你的是**保证金余额**。

我的配置（示意）：

```json
{
  "symbol": "BTC_USDT",
  "contract": "perpetual",
  "lower_bound": 55000,
  "upper_bound": 75000,
  "grid_number": 40,
  "leverage": 2,
  "investment_usdt": 400,
  "guardrail": { "min_account_balance_usdt": 40, "block_new_orders_if_below": true }
}
```

## 到底要多少本金

我大约同时跑 10 个网格，需要留 **40 USDT 自由余额** 当护栏缓冲。

为什么要护栏？价格一动机器人就一直挂单，余额不够下一单或维持保证金时，交易所可能强平你一部分仓位。我加了一个余额检查，低于阈值就**禁止开新单**——这是我跑过最重要的安全代码：

```python
def should_place_order(free_balance_usdt: float, min_balance_usdt: float = 40.0) -> bool:
    """余额不足时禁止网格开新单。"""
    if free_balance_usdt < min_balance_usdt:
        return False  # 护栏：保住保证金，避免被强平
    return True
```

这不是"好习惯"，而是"可控回撤"和"被强平"的分界线。

## 为什么大多数网格会爆

核心死法只有一个：**趋势市**。网格是假设均值回归的区间策略。BTC 单边猛拉时：

- **上涨趋势**：机器人一路卖光库存，然后空仓错过行情——这是机会成本，不是亏损；
- **下跌趋势**：机器人一路向下买，堆出一个巨大多头，浮亏累积到保证金率崩掉被强平。

第二种才是账户归零的地方。网格永远"不知道"趋势变了，它只会一直接那个永不回来的"下跌"。所以盯**保证金率**才是关键。

| 行情         | 网格表现           | 典型结果           | 风险   |
|--------------|--------------------|--------------------|--------|
| 震荡/插针    | 频繁买卖循环       | 稳定小赚           | 低     |
| 强上涨       | 卖光库存、空仓     | 错过涨幅、不亏     | 中     |
| 强下跌       | 累积多头仓位       | 浮亏持续扩大       | 高     |
| 出区间(上)   | 停止、无仓位       | 不交易、无手续费   | 低     |
| 出区间(下)   | 停止、满仓多       | 最大回撤暴露       | 极高   |

## 我踩的 4 个坑

**坑 1 —— 区间太窄。** 我第一个网格只设了 $1,000 带宽，理由是"网格越密=循环越多=赚越多"。循环确实多了——直到某天 BTC 一天走 $3,000，机器人卡在区间外两周不动，回程又被套多。窄区间放大的是手续费，缩短的是赚钱时间。宽区间才扛得住波动。

**坑 2 —— 没有回撤止损。** 我好几个月没设自动止损，自我安慰"机器人会回来的"。有时候确实回来了；有时候仓位涨到再跌 5% 就要被强平。网格必须有一个外部回撤止损，比如"浮亏超过投入保证金的 X% 就平掉重估"。没有它，你就是在赌一个趋势市会打破的均值回归假设。

**坑 3 —— 杠杆过高。** 早期我开 5x 想放大收益，它也放大了每一笔逆风：5x 下，累积仓位对面跌 20% 就是强平，不是账面亏损。降到 2x（如上配置）每循环收益少了，但机器人活下来了。杠杆决定一个坏星期是"教训"还是"出局"。

**坑 4 —— 忽略资金费率。** 永续合约每 8 小时收一次**资金费率**。长期下跌里我的网格满仓多，全程都在为这个仓位付资金费——一层叠在浮亏和手续费之上的隐性成本。单次不多，但正好在你已经流血的时候复利累积。下重手前、以及长期单边时，都要看资金费率。

## 6 个月到底教会我什么

示意地讲：震荡月里机器人小赚，趋势月里基本吐回去，扣完手续费净收益大约"平到微赚"。诚实的结论是——BTC 网格机器人是**波动收割工具，不是保本收益**。它奖励纪律，远胜于奖励调参技巧。

## 怎么在爆仓前发现问题

盯保证金率和回撤，别盯每日 PnL。我设的是保证金率 < 10% 预警、< 5% 硬暂停，这样在交易所强平你之前就能收到提醒。

## 不用天天盯盘也能看住网格

跑了半年后我不再手动刷 App，所有数据集中在一个地方看。[GridLens](https://gridlens.vercel.app) 监控网格的 PnL、回撤和保证金健康度，网格卡在区间外或保证金率掉下来时会告警——就是把上面这些护栏自动化了。
